# إنجاز | Enjaz Planning Platform

منصة تجريبية لإدارة ومتابعة الخطط المؤسسية باستخدام **Node.js وExpress وMySQL اختيارية**، مع واجهة عربية RTL ومركز إشعارات.

## الوظائف المتاحة في النسخة الحالية

- لوحة متابعة تعرض الأنشطة، متوسط الإنجاز، الأنشطة المتعثرة والمكتملة.
- فلاتر حسب الدائرة والربع والنصف السنوي والسنة الكاملة.
- مركز إشعارات تجريبي وعدّاد للإشعارات غير المقروءة.
- تحديث نسبة الإنجاز ببيانات تجريبية **مؤقتة** فقط.
- قراءة الأنشطة من MySQL اختبارية عند ضبط متغيرات الاتصال، دون السماح بالتحديث من الواجهة.

## التشغيل المحلي

1. ثبّتي Node.js الإصدار 20 أو أحدث.
2. نفّذي `npm install` ثم `npm start`.
3. افتحي `http://localhost:3000`.

لا يلزم MySQL لتجربة الواجهة. يبدأ الخادم محلياً افتراضياً على `127.0.0.1` ولا يستقبل طلبات من الشبكة الخارجية.

## MySQL للاختبار فقط

أنشئي قاعدة بيانات اختبارية من hPanel أو phpMyAdmin، ثم نفّذي `schema.sql` بعد اختيار القاعدة. انسخي `.env.example` إلى `.env` واضبطي `DB_HOST` و`DB_USER` و`DB_PASSWORD` و`DB_NAME`. **لا ترفعي `.env` أو بيانات الاتصال إلى GitHub.**

## واجهات API

- `GET /api/health`
- `GET /api/reporting-periods`
- `GET /api/tasks`
- `POST /api/tasks/:id/progress` — يعمل في Demo فقط
- `GET /api/notifications` — إشعارات افتراضية
- `POST /api/notifications/:id/read` — يعمل في Demo فقط

## تنبيه أمني

**هذه نسخة Proof of Concept وليست جاهزة للنشر العام أو لإدخال بيانات حكومية حقيقية.** لا تتضمن تسجيل دخول أو أدواراً وصلاحيات أو سجلات تدقيق أو موافقات إدارية أو إشعارات حقيقية متعددة المستخدمين. القيم والأسماء والإشعارات الموجودة للتوضيح فقط.
